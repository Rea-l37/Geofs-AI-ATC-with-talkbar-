📻 GeoFS AI (GPT) ATC Addon
Transform your GeoFS flying experience with an intelligent, context-aware AI Air Traffic Control powered by Puter.ai (GPT). Interact with local tower controllers via text or voice, receive realistic speech readbacks, and keep your flight screen clean with a fully customizable floating interface.

✨ Key Features
🧠 Smart AI Tower Controllers: Communicates using realistic, concise aviation terminology. Every controller is uniquely generated based on the tuned airport's ICAO code.

🛩️ Live Flight Context: The AI automatically receives your real-time telemetry—including aircraft type, ground speed, heading, altitude, wind speed, and distance to the field—for accurate clearances and instructions.

💬 Push-To-Talk (PTT) Voice & Text Transmissions: Transmit via text or speak directly into your microphone using integrated browser speech recognition.

🔊 Dual Voice Synthesis: Both pilot transmissions and ATC responses are spoken aloud through synthesized radio voices for immersive audio feedback.

📏 Distance & Static Simulation: Real-time distance calculations using the Haversine formula. Exceeding 50 NM triggers radio static and out-of-range warnings.

📐 Scalable & Draggable UI: Easily reposition the ATC panel anywhere on screen or drag the bottom-right corner to resize the chat history box.

🔘 Dedicated Toggle Button: Includes a sleek 📻 TOGGLE ATC screen button to instantly show or hide the control panel.

⌨️ Smart Input Protection: Typing in the ATC box automatically suppresses keypress propagation, preventing accidental simulator keybind triggers (flaps, gear, brakes, etc.).

🛠️ Installation
Install a userscript manager extension such as Tampermonkey or Violentmonkey.

Create a new script in your extension dashboard.

Copy and paste the full script code and save it.

Launch or refresh GeoFS.

✈️ How to Use
Open the Radio: The ATC panel loads automatically once your aircraft spawns. Click 📻 TOGGLE ATC at the top right to hide or show the panel at any time.

Tune a Frequency: Click TUNE FREQ. It auto-detects the nearest airport or lets you manually enter any valid ICAO code (e.g., KJFK, EGLL, KSFO).

Transmit:

Text: Type your message in the input box and press Enter or click TX.

Voice: Click 🎤 PTT (VOICE), grant microphone permissions if prompted, and speak your transmission.

Note: Requires a browser supporting the Web Speech API (such as Chrome or Edge) for voice recognition and text-to-speech features.
